# Ficha de la Chrome Web Store por idioma

Un archivo por idioma con los dos campos que el panel de desarrollador pide por idioma:

- **Resumen** (≤ 132 caracteres): el mismo texto que `appDesc` en `i18n/<locale>.json`.
- **Descripción**: versión traducida de la descripción larga de `store/LISTING.md`.

Cómo cargarlos: Developer Dashboard → el elemento → **Ficha de Play Store** → en el selector de
idioma de arriba, **Añadir idioma** → elegir el idioma → pegar resumen y descripción → Guardar
borrador. Repetir por idioma y al final **Enviar para revisión**. Las capturas se pueden dejar
en común (las de la ficha actual valen para todos los idiomas).
