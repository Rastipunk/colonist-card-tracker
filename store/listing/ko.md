# 한국어

## 요약

colonist.io용 카드 카운터: 훔치기 확률, 은행, 개발 카드, 주사위 표시. 연구를 위해 익명으로 게임을 기록합니다.

## 설명

Colonist Card Tracker는 colonist.io에서 플레이하는 동안 각 플레이어가 자원별로 카드를 몇 장 들고 있는지 보여줍니다.

• 자원 분배, 건설, 거래, 버리기, 독점을 모두 셉니다.
• 상대가 다른 상대에게서 보이지 않는 카드를 훔치면 각 경우의 확률을 계산하고 이후의 플레이로 정밀도를 높입니다.
• 은행, 손에 든 개발 카드와 사용한 개발 카드, 기대 승점, 주사위 히스토그램을 표시합니다.
• 서버가 보내는 카드 합계와 대조하여 불일치가 있으면 표시합니다.
• 어떤 인터페이스 언어에서도 동작하며 게임 도중 페이지를 새로고침해도 상태를 유지합니다.

공개 연구. 이 확장 프로그램은 무료입니다. 대신 사용하려면 게임 기록(플레이, 거래, 채팅)을 익명으로 저장하는 데 동의해야 합니다. 모든 플레이어 이름은 데이터가 브라우저를 벗어나기 전에 코드로 대체되며, 그 코드를 만드는 키는 내 설치 환경 밖으로 절대 나가지 않습니다. 데이터는 게임 내 의사결정과 협상에 관한 연구 목적으로만 수집됩니다. 동의는 옵션에서 언제든지 철회할 수 있습니다.

비공식 도구이며 Colonist와 관련이 없습니다. 서버가 이미 브라우저로 보내는 트래픽만 읽을 뿐, Colonist로 아무것도 보내지 않고 게임을 변경하지도 않습니다.
